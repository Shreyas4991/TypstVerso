How to use the repository

← Samples GitHub repository

  1. Check the required installations

    Install Lean with elan and Lake, Typst 0.15 or later, Python 3.9 or later, and Git. Check that these commands work in your terminal:

    lean --version
lake --version
typst --version
python3 --version
git --version

    On Windows, use py --version for Python. If a command is missing, complete that tool's installation before continuing.

  2. Create a repository from the template

    On GitHub, select Use this template → Create a new repository. Choose an owner and name, then create the repository.

    Clone your new repository and enter its folder. Replace YOUR-USER and YOUR-REPO below:

    git clone https://github.com/YOUR-USER/YOUR-REPO.git
cd YOUR-REPO

  3. Install the Python dependency and build

    Run these commands from the repository folder, which contains build.py.

    On macOS or Linux:

    python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python build.py --all

    On Windows:

    py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe build.py --all

    The first build downloads Lean dependencies and may take a while. Open main.html or main.pdf in each template's documents/article/build/, documents/book/build/, or documents/slides/build/ folder.

    Edit the corresponding main.typ file in documents/ and put your Lean code in LeanProject/LeanProject/Basic.lean. To rebuild when files change, run:

    .venv/bin/python build.py --watch --all

    On Windows, replace .venv/bin/python with .venv\Scripts\python.exe. Leave the command running while you edit, refresh the HTML in your browser after a rebuild, and press Ctrl+C to stop it.
